# Bkper Calculator

Calculator keeps quick arithmetic inside the Bkper context, so you do not need to switch to a phone or another browser tab while working in a Book.

## How to use it

1. Open a Bkper Book.
2. Open the **More** menu and choose **Open Calculator**.
3. Enter an expression such as `3000 - 2000`.
4. Press **Enter** or choose **Calculate**.
5. The expression and result are added to the history, and the result remains in the input for the next calculation.

The calculator supports `+`, `-`, `*`, `/`, parentheses, decimals, and negative numbers. It follows the current Book’s decimal separator and fraction-digit settings. Grouped numbers are interpreted according to the Book’s locale, and results use Bkper’s configured output format.

History is kept separately for each Book in the current browser session. It is limited to the latest 20 calculations and is never written to the Book.

## Availability

The app is initially available to users in the Bkper domain. It will be tested internally before being submitted for wider publication.
